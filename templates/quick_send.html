How it works
  1. Enter only the destination email in the section for the provider and supplier type you want to test. Each section shows the server/region it resolves to.
  2. Supplier name, product, quantity and target price are all filled in with fixed test defaults automatically.
  3. Clicking Send calls the same POST /send endpoint as the full Send RFQ form — so the conversation is created as a draft first, then flipped to Open once the provider accepts it.
  4. The email's subject is [RFQ - id] - … and it carries its own Message-ID. There is no per-conversation reply address: a reply is matched by Message-ID/References, falling back to that subject prefix.
  5. All sections send the English HTML template regardless of supplier type.
  6. Alibaba: The single "Send to Both" button sends to both Chinese and Non-Chinese suppliers with separate conversations, using the Alibaba Hong Kong and Singapore servers respectively.
  7. On a successful send, the conversation's tracking page opens automatically in a new tab (or multiple tabs for Alibaba).
